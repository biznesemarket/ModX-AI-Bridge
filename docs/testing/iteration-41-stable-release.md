## Notes

- Transport archives are not byte-reproducible (embedded file timestamps), so each build has its own SHA-256;
  the metadata is regenerated by `scripts/release-candidate.php`. This is the same caveat recorded for the
  Release Candidate.
- The gate is run twice inside `stable-gate.sh` (direct `composer test-modx` plus `quality-gate.sh`), which is
  why two `RELEASE:` blocks appear per certify run.
