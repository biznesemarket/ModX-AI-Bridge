# Stable Release — 0.1.3

Release: `aibridge-0.1.3.transport.zip`

## Highlights

- **TypeScript SDK live HTTP E2E.** `scripts/ts-live-check.sh` + `scripts/ts-live-runtime.php` drive the
  compiled SDK against a real MODX `/api/ai/v2/*` boundary: 11 `node:test` cases covering authentication
  (401 with an unknown token), capabilities, profile isolation, site schema/fingerprint, content
  contract/validation, resource create and update through the real queue with a `worker.php --once` loop,
  delete/publish policy denials, and MCP `initialize`/`tools`/`tools/call`/`resources/read`. Wired into
  `scripts/test-modx.sh` as step 10b; `npm test` stays offline, `npm run test:live` runs the live suite.
- **Defect #35 fixed.** `waitForJob()` in both SDKs read only `data.status`/`status`, while the real
  `GET /api/ai/v2/jobs/{id}` envelope is `{success, job:{status}}`, so polling timed out against the live
  service. Both clients now read `data.status → job.status → status`; runtime tests lock the real shape.
- **Release process.** All version identities, including `README.md` (embedded into the transport package
  manifest), are committed before the certification gate, so the pre-release dispatch and the tag run produce
  the identical artifact hash.
