# Stable Release — 0.3.0

Release: `aibridge-0.3.0.transport.zip`
Tag: `v0.3.0`
Built by: `scripts/release-candidate.php` (invoked in the MODX container with `MODX_ROOT=/var/www/html`)

## Highlights

- **Template variables in the read-back projection.** `GET /api/ai/v2/resources/{id}` and the `resource_read`
  MCP tool now return a `tvs` map (TV name -> `string|null`; structured values are JSON-encoded) for every TV
  bound to the resource template. The map is added inside the existing `resource.read` operation / `resource:read`
  scope, so the SecurityDecisionPipeline, IP allowlist and profile behavior are unchanged.
- **`resource.read` capability listing.** `CapabilityCatalog` now advertises the read operation
  (`scope: resource:read`, status `available`), closing the Iteration 51 gap.
- **Typed TypeScript SDK read-back.** `ResourceProjection` / `ResourceTvValues` / `ResourceReadResponse` types
  and a typed `getResource()`.
- Additive minor over `0.2.0`: no new route, scope, setting, schema or migration; a resource without TVs returns
  `tvs: {}` and existing clients keep working.
