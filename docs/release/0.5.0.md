## Highlights

- **MCP resource template `modx://resource/{id}`.** `resources/read` resolves URI templates (extracting `id`)
  and returns the read-back projection for one persisted resource — the same payload as the `resource_read`
  tool and `GET /api/ai/v2/resources/{id}` — under the existing `resource.read` / `resource:read` operation. A
  missing or soft-deleted resource returns JSON-RPC `-32002 Resource not found` (`reason: resource_not_found`).
- **`resources/templates/list`.** New MCP method advertising `uriTemplate` entries; concrete resources
  (`modx://site/schema`, `modx://site/fingerprint`) are unchanged and still returned by `resources/list`.
- **SDKs.** `resourceTemplates()` added to the PHP and TypeScript MCP clients.
- Additive minor over `0.4.0`: no REST route, scope, schema, migration or setting change.
