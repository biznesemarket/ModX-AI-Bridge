## Highlights

- **Recursive parent filter.** `GET /api/ai/v2/resources` and the `resource_list` MCP tool accept an optional
  `depth` (1..10, default 1) alongside `parent`. `depth = 1` keeps the historical direct-children behaviour;
  higher values include descendants down to that many tree levels. Soft-deleted resources are skipped while
  walking, so a soft-deleted node hides its subtree. `depth` without `parent`, or a value outside 1..10,
  returns `400 invalid_filter`.
- **`parent` sort.** `parent` is now a supported `sort` column.
- **Coverage.** New integration test `RestApiTest::testResourceListFiltersByParentDepthAndSortsByParent`
  covers direct-children defaults, two-level and full-subtree recursion, sibling-tree isolation, an empty
  page, the invalid `depth` matrix, `sort=parent` ordering and soft-delete pruning.
- Additive minor over `0.8.0`: no new scope, route, schema, migration or setting change; the response shape
  is unchanged.
