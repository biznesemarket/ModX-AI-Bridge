# Stable Release — 0.1.1

Release: `aibridge-0.1.1.transport.zip`
Tag: `v0.1.1`
Built by: `scripts/release-candidate.php` (invoked in the MODX container with `MODX_ROOT=/var/www/html`)

## Highlights

- **Fixes system settings packaging (Defect #34).** `_build/elements/settings.php` chained
  `fromArray()` off `new modSystemSetting()`, but `xPDOObject::fromArray()` returns void, so every entry was
  `null` and `build.php` skipped it. Releases `0.1.0` and earlier shipped no `aibridge_*` system settings;
  `0.1.1` ships all 19.
- **Reproducible transport builds.** Deterministic vehicle guids (xPDO otherwise uses
  `md5(uniqid(rand(), true))`) plus an archive normalized to sorted file entries and a fixed
  `SOURCE_DATE_EPOCH` timestamp. Two builds — local and CI — produce an identical SHA-256.
- **CI hardening.** PHP `sdk` suite and TypeScript SDK gate run in the fast `deterministic` job; workflows
  use Node.js 24 action runtimes; the `Release` certification job uploads `dist/**` release evidence.
